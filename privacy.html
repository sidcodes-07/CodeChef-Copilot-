CodeChef Copilot Privacy Policy

Effective date: 2026-10-05

Information processed

When you ask CodeChef Copilot to help with a question, the extension reads the visible question text and answer options, or the visible programming problem statement and your current editor contents. It sends the relevant structured question context to the CodeChef Copilot backend to generate an answer. The backend forwards that context to NVIDIA's model API for processing. Do not use the extension with confidential or personal information.

Storage and service logs

The extension stores its current progress and status locally in browser extension storage. The application backend does not intentionally save submitted question text or generated answers to a database. The backend uses request IP addresses in memory for rate limiting. The hosting provider may process connection and operational metadata under its own policies.

Third-party services

NVIDIA processes prompts sent by the backend under its applicable service terms and privacy practices. Render hosts the backend and may process service and network metadata. Review those providers' current policies before using this extension.

Permissions

The extension runs on CodeChef pages to inspect the visible learning problem, select a detected answer, interact with a supported code editor, and observe results. It contacts the CodeChef Copilot backend to request model output. It does not automatically submit final assessments.

Contact

This policy may be updated when the extension or its service providers change.
